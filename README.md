1. Установка Python

Установить Python с офф сайта, если еще не установлен(на macOS и Linux Python вроде установлен по умолчанию , команда для проверки: python3 --version, если вывелась версия значит установлен).

Скачать установочный файл версии Python 3.10 + для выбранной операционной системы (Windows, macOS, Linux).

Запустить установку с выбранной  опцией - Add Python to PATH.

2. Установка Git

Перейти на официальный сайт Git.

Скачать установочный файл для выбранной операционной системы.

Установить Git, следуя инструкциям.

3. Клонирование репозитория

Открыть терминал (Command Prompt на Windows, Terminal на macOS/Linux).

Перейти в директорию, где будет размещен проект, с помощью команды: cd путь_к_директории.

Выполнить команду для клонирования репозитория:
git clone -b feature/playwright --single-branch [https://github.com/Vladimir-Kryvetski/ui_autotests.git](https://github.com/Vladimir-Kryvetski/ui_autotests.git) .

**4. Создание и активация виртуального окружения.**
4.1 В директории проекта создать виртуальное окружения с помощью команды:
python -m venv myenv

4.2 активировать виртуальное окружение командой:

myenv/bin/activate

**После выполнения данной команды в скобках должно появиться (myenv) перед именем пользователя**

5. **Установка зависимостей в активированном виртуальном окружении (должно отображаться myenv перед именем пользователя)**

Перейти в директорию с клонированным репозиторием(дирректория должна содержать файл requirements.txt):
cd имя_директории

Установить необходимые зависимости:
pip install -r requirements.txt

6. Запуск тестов из корневого каталога проекта в **активированом виртуальном окружении**

Для запуска негативных тестов выполнить команду:
pytest -m submit_application_negative_data

Для запуска позитивных тестов выполнить команду:
pytest -m submit_application_positive_data

7. Просмотр отчетов

Отчеты будут храниться в виде HTML файла в директории reports в корне проекта

Отчеты по тестам можно будет просмотреть в браузере

**Обновеление автотестов**

1. Перейти в каталог с проектом
2. Стянуть изменения с удаленного репозитория , используя команду git pull origin feature/playwright
3. Активировать виртуальное окружение, например командой **myenv/bin/activate**, где **myenv** имя виртуального окружения
4. Обновить зависимости командой pip install -r requirements.txt
5. Находясь в корневом каталоге , запустить автотесты командой: pytest или pytest -k "имя_ключа"(запустит автотест с выбранным ключом)
